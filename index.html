DOCUMENTATION

Understand the evidence.

AQUAQUN is a focused diagnostic aid—not a penetration test and not a guarantee of security.

How to run a scan

Enter a public domain or URL. The scanner normalizes the hostname and requests DNS and best-effort RDAP data from the configured Worker.

How to read statuses

Passed means a response was received for that operation; warning means the result needs context; not supported means no check was performed.

Known limitations

HTTPS certificate details, headers, HTTP redirects, reachability and robots/sitemap retrieval are not connected in this build.

What DNS means

Records describe resolver responses. They do not prove a web server is reachable or secure.

Registration data

RDAP fields may be absent, redacted, unsupported, or temporarily unavailable.

Read findings carefully

A missing header is a signal to investigate, not automatic proof of an exploitable vulnerability.

ABOUT AQUAQUN

Technical clarity over security theatre.

AQUAQUN aims to make public website diagnostics understandable, evidence-based, and transparent about what it cannot verify.

This build includes a responsive frontend and an optional Cloudflare Worker for limited DNS and best-effort RDAP lookups. It intentionally does not expose arbitrary URL-fetching endpoints because this implementation cannot guarantee connection-time IP pinning for SSRF protection.

No account, database, persistent scan history, or security score is included. The network graphic is conceptual—not a live infrastructure trace. Before public launch, configure allowed CORS origins, rate limits, hosting logs, and a monitored contact address.
